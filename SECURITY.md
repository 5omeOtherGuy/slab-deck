# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/5omeOtherGuy/slab-deck/security/advisories/new).
Do not open a public issue.

You will get an acknowledgement within 7 days. Fixes go through a private security advisory: fix, release,
publish the advisory, and credit you as the reporter unless you prefer otherwise.

## Supported versions

slab-deck is in pre-release. Fixes land on `main`, and once versions are tagged, the latest minor version is
supported.
